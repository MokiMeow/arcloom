# AI assistance disclosure

The initial Arcloom concept and workflow were proposed by the project team. AI assistance was used to research implementation options, write and refine the backend and frontend, produce tests and documentation, and inspect errors during execution.

The build used actual Python tests, real FalkorDB integration, a separate-process persistence test, TypeScript/Vite compilation and browser automation. This disclosure does not imply manual security certification, exhaustive coverage or live provider benchmarking. Seeded synthetic vulnerabilities are deliberate test fixtures, not newly discovered vulnerabilities in a real company.

The team remains responsible for reviewing the code, explaining the architecture, protecting credentials, selecting a license, confirming event eligibility and accurately describing which demonstrations use deterministic versus live model planning.
